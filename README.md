#  Установка и настройка виджета "PepeLand 11" для OBS

##  Шаг 1. Подготовка файлов
Для работы виджета вам понадобится 4 файла, которые должны находиться в ОДНОЙ папке.
1. index.html — основа виджета (структура).
2. style.css — стили и цвета (дизайн).
3. script.js — логика работы (анимации и тайминги).
4. pepe.svg — ваша картинка с Пепе (убедитесь, что она называется именно так, с расширением .svg).

Совет: Создайте отдельную папку на рабочем столе под названием "PepeLand_Widget" и поместите туда все 4 файла.

---

##  Шаг 2. Добавление в OBS
1. Откройте OBS Studio.
2. В панели "Источники" нажмите на плюсик (+) и выберите "Браузер".
3. Задайте имя источнику (например, "Pepe Widget") и нажмите "ОК".
4. В открывшемся окне свойств настройте следующие параметры:
   - Ширина: 400
   - Высота: 150
   - Поставьте галочку напротив пункта "Локальный файл".
   - Нажмите кнопку "Обзор" и выберите файл index.html из вашей папки.
   - ВАЖНО: Убедитесь, что галочка "Выключить источник при неактивности" СНЯТА. Если она стоит, таймеры анимации собьются, и виджет может перестать появляться.
5. Нажмите "ОК".

---

##  Шаг 3. Размещение на экране
Виджет появится в центре вашего экрана в OBS.
- Вы можете перетащить его мышкой в любой угол (например, в левый нижний угол).
- Вы можете изменить размер, потянув за красные уголки рамки источника. Благодаря использованию SVG-картинки и векторного текста, качество не потеряется при масштабировании.

---
 Шаг 4. Как это работает (Тайминги)
Виджет запускается автоматически при открытии OBS.
- Цикл показа: Виджет появляется каждые 90 секунд.
- Длительность показа: Плашка висит на экране 20 секунд, после чего плавно исчезает.
- Анимация:
   Появляется полупрозрачная плашка с логотипом.
   Выплывает надпись PepeLand.
   Рядом начинает крутиться счетчик от 0 до 11.
   Текст PepeLand 11 сдвигается наверх и увеличивается.
   Снизу выплывает ссылка pepeLand.net.

##  Шаг 5. Кастомизация (Изменение настроек)
Если вы хотите изменить текст, скорость или частоту появления, откройте файл script.js с помощью Блокнота (или любого редактора кода).

	В самом верху найдите блок с таймингами (время указано в миллисекундах, где 1000 = 1 секунда):
  	1. const TIME_SHOW_BOX = 1100;       // Появление рамки
  	2. const TIME_SHOW_NAME = 1500;     // Появление текста "PepeLand"
  	3. const TIME_START_COUNTER = 1000; // Начало отсчета
  	4. const TIME_COUNTER_SPEED = 450;  // Длительность отсчета
  	5. const TIME_MOVE_UP = 6000;       // Сдвиг наверх и появление ссылки
  	6. const TIME_HIDE = 20000;         // Через сколько скрыть

	В самом низу файла: 
	7. setInterval(runAnimation, 90000); // 90000 = 90 секунд (интервал между показами)

Измените нужные цифры, сохраните файл (Ctrl+S) и в OBS нажмите "Обновить кэш текущей страницы" (или просто перезапустите OBS).
